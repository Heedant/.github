# Heedant

**Every position, every order, every account. One screen, whichever OMS holds them.**

Heedant is a read-only risk view across order management systems, built for proprietary
trading risk desks. It streams each change to the desk the moment the OMS reports it, and
it cannot place, change or cancel an order.
